# Magpie 功能移植：使用与边界

参考 [yetone/magpie v0.1.4777](https://github.com/yetone/magpie/tree/v0.1.4777) 的交互和原生会话格式，接入 cc-switch 的 Rust/Tauri 和 React 实现，不依赖 Magpie 进程或 Bun。[参考项目许可](../third-party/magpie-LICENSE.txt)。

| 功能 | 在哪里使用 | 实际行为 |
|---|---|---|
| 配置体检 | 已接管的应用 → 模式栏 → **配置体检 / 退出预览** | 对比盘上字段、当前路由契约和回直连的目标，不显示值。可以关闭保留现状、重新应用路由，或在回到原直连供应商时核对预览后退出。Claude Code、Codex、Gemini CLI、Grok Build 支持。 |
| 跨 Agent 接续 | 会话管理 → 本地 Claude Code 或 Codex 主会话 → 行菜单 → **复制到另一个客户端继续** | 目标客户端先初始化，原项目目录仍需存在。只在目标原生会话目录另建副本，返回可复制的恢复命令。源会话、数据库索引和子会话不改动；不会启动终端或请求模型。 |
| 同步差异 / 撤销 | 设置 → WebDAV/S3 → 上传或下载 | 显示供应商、提示词、MCP、Skills 与技能文件的增删改，最多展示 500 行。**仍是完整快照**，不是勾选行做选择性合并。确认绑定方向、存储位置、远端清单和本地内容；远端已存在但没有强 ETag 时，不执行无法保证并发安全的手动覆盖。 |
| 项目资源与工作树 | 项目 Profile → 管理 → **绑定到 Git 项目** | 选择现有 Git 工作树根目录、客户端和已有 Profile。只投影该 Profile 的 MCP、Skills、指令，不改全局开关或供应商。可只操作当前 checkout，也可显式覆盖目前登记的工作树；新建工作树后需再预览并应用。 |
| MCP 工具控制 / Skills 按需 | MCP → 编辑已保存的服务 → **按客户端启停工具**；Skills 页 → **全局按需索引**，或项目绑定 → **Skills 按需加载** | 只有主动点击才会连接服务（stdio 会启动本机保存的命令）并发 `tools/list`；不调用工具。Codex 写 `disabled_tools`，Gemini CLI 写 `excludeTools`，Claude Code 使用本机用户设置的 `permissions.deny`。其他客户端不宣称强制生效。项目 Skills 可在逐项写入和单索引之间选。 |
| 上下文与选路解释 | 启用代理日志 → 用量 → 请求详情 → 诊断 | 显示实际选择与跳过原因，以及每次上游尝试的系统指令、工具定义、对话、工具结果、媒体表示所占估算字节。无需开启正文捕获。计数不是供应商 tokenizer 或收费数字；缓存命中量仍看服务商上报。 |

**哪些内容不会搬：**会话迁移只取可识别主线，工具只作历史文本（节选），不会生成可重放的调用，不迁移图片、隐藏推理、签名和旧系统指令。输入上限为解压后 32 MiB；超限报错，不生成半个会话。不支持把只读子代理变成可执行主会话。

**配置预览边界：**比较主配置文件，登录凭据、外部模型目录和附加资源由现有切换事务处理；读预览不打开钥匙串，不做登录刷新。Codex 里依赖登录态的字段明确标为条件项。重新应用只在主动确认后执行。Claude Desktop 与“退出后另换一家”的两步操作不承诺完整字段预览。

**同步边界：**上传预览方向是“本机 → 远端”，下载是“远端 → 本机”。撤销仅限本次进程内上一次成功下载，恢复 DB 和 Skills，不回写远端；下载后本机同步数据发生变化会拒绝撤销。磁盘备份仍可通过现有备份管理另行恢复。源数据、密钥和 SQL 不返回给差异界面。

**项目文件保护：**每个 checkout 存独立的本机所有权记录。已有用户文件、同名文件、符号链接和已被手改的受管文件不覆盖。MCP 文件可能含密钥，要求先用 Git 本地 `info/exclude` 忽略对应的 `.mcp.json` 或 `.codex/config.toml`；不会偷偷修改 Git 跟踪状态。Codex 项目级设置是否受信由用户在 Codex 中决定。选择“移除”仅清理程序记录且内容未变的文件。未关闭的全局资源仍然全局可见。

**Skills 与工具控制的区别：**索引模式只在选定项目写一个索引，让客户端按需读取本机来源目录里的 `SKILL.md` 和附件；不需要安装通用 MCP Hub，也不生成独立技能的所有快捷命令。逐项写入模式保留各技能自身的目录结构。MCP 工具禁用不靠提示词；原配置中的禁用项不由这个入口解除。

**全局 Skills 索引：**选择 Claude Code / Codex，只给选中的库技能发布一个 `cc-switch-skill-index/SKILL.md`。不替你删任何已有的直装项；要减少提示词重复，可先把对应直装项从该客户端停用，再加入索引。选择空列表只移除程序自己写入且内容未变的索引。使用本机资料库时才有意义；共用的原生资料库、仅允许手动调用的技能、同名用户文件均拒绝接管。安装/删除后可重新保存以刷新。

# CC Switch v4.0.40-codex-auth-144

合入上游 v4.0.40 及后续提交至 `e6fd4accd`，并适配 fork 的网关、账号路由、附加数据库和流式保护。

- 代理在非 loopback 监听下也按连接地址检查本机请求的 Host；保留连接预算、请求头超时和完整关闭机制。
- 用量脚本限制重定向、自转发、响应大小和 JavaScript 插值；SQL 导入拒绝触发器与视图，并限制大小和执行时间。
- 数据库接入 WAL、读缓存与阻塞工作线程，保留 fork 附加数据库及网关账本；恢复与导入后清除缓存。
- SSE 日志限制按单事件判断，避免将同一数据块中的多个正常事件误判为超限；保留共享 framer 的硬事件上限和错误传播。
- 合入 AGY 插件、T3 Code / ACP 会话、授权中心排序与隐藏、Grok 官方账号绑定、MiMo 用量和缓存命中率显示。
- 新增 CodeBuddy Code 供应商、官方账号、MCP、Skills、会话和用量支持；改善 i18n 与托盘加载，复用 Claude 上游连接，并修复 macOS 更新重启后的 Dock 图标。
- 采用上游的测试拆分与 CI 并发优化，继续运行完整 Clippy、前端测试、官方 Codex 配置契约和 Windows / WSL2 文件系统检查。

原有 fork 的账号重试、配额归一、会话子代理只读保护、Skills 迁移与同步修复及更新地址保留。上游删除项同步处理，原有本地文档未改动。

上游详细说明：[v4.0.40 中文发布说明](https://github.com/farion1231/cc-switch/blob/v4.0.40/docs/release-notes/v4.0.40-zh.md)。

发布页提供 macOS universal DMG / ZIP、Windows x86_64 / ARM64 MSI 与便携版，以及 Linux x86_64 / ARM64 AppImage / DEB / RPM。`.tar.gz` 用于应用自动更新。
